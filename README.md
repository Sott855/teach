# Virtual Zoo (Виртуальный зоопарк) 🦁🐼

Учебный проект на языке Go, демонстрирующий применение основных принципов объектно-ориентированного программирования (ООП): **инкапсуляции**, **полиморфизма** и **интерфейсов**.

---

## 📌 Описание задачи

Система моделирует работу виртуального зоопарка:
- Реализован контракт интерфейса `Animal` с методами `MakeSound()`, `GetName()` и `GetInfo()`.
- Создана структура `animal` с приватными полями (`name`, `species`, `age`, `sound`) и конструктором `NewAnimal`.
- Реализован полиморфный вывод информации о животных через функцию `ZooShow`.
- Добавлена структура смотрителя `Zookeeper` с методом кормления `Feed`.

---

## 🛠 Технологии

- **Язык программирования:** Go 1.20+
- **Основные концепции:** Interfaces, Structs, Encapsulation, Polymorphism
